# Contributing to RSI Tech projects

Thank you for contributing.

1. Read the target repository's README, license, security policy, and local
   contribution instructions.
2. Open an issue before a large behavioral or architectural change.
3. Keep changes focused and add tests for changed behavior.
4. Run the repository's documented verification commands.
5. Do not include secrets, private data, generated credentials, or unlicensed
   assets.

By contributing, you confirm that you have the right to submit the work under
the repository's license.

## Where to start

- Browse public repositories:
  https://github.com/orgs/rsitech-ai/repositories
- Prefer small, reviewable pull requests with a clear problem statement.
- For security reports, follow
  [SECURITY.md](https://github.com/rsitech-ai/.github/blob/main/SECURITY.md).
- Community standards are in
  [CODE_OF_CONDUCT.md](https://github.com/rsitech-ai/.github/blob/main/CODE_OF_CONDUCT.md).

Project-specific contributing guides override this document when they differ.
