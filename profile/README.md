# RSI Tech

RSI Tech builds local-first software for research, verification, and operational clarity.

## Open source

### AssetRail

AssetRail is an offline macOS prototype for deterministic crypto withdrawal route planning with synthetic fixtures. It does not connect to exchanges or wallets and cannot submit a withdrawal.

[View the repository](https://github.com/rsitech-ai/asset-rail) · [Read the v0.1.0 release](https://github.com/rsitech-ai/asset-rail/releases/tag/v0.1.0)
