# Security Policy

Do not report suspected vulnerabilities in a public issue.

Email [info@rsitech.ai](mailto:info@rsitech.ai) with:

- the affected repository, version, or commit
- impact and reproduction steps
- any safe supporting evidence

Do not include credentials, personal data, or live exploit payloads unless an
encrypted exchange has been agreed.

Supported versions and response expectations are documented in each
repository's release notes or support policy when available. RSI Tech does not
yet guarantee a formal SLA for every public preview.
